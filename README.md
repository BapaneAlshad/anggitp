# Personal Branding Anggit Prakoso

Skeleton awal website personal branding berbahasa Indonesia, dibangun dengan Next.js App Router, TypeScript, React, dan Tailwind CSS. Target deployment adalah Vercel.

## Menjalankan project

```bash
npm install
npm run dev
```

Buka `http://localhost:3000` di browser.

## Pemeriksaan kualitas

```bash
npm run lint
npm run build
```
